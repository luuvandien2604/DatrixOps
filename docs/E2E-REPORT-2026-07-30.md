# Isolated E2E report — 2026-07-30

## Scope

The candidate source tree was copied to two isolated Docker Compose projects on
an existing Ubuntu 25.04 VPS. The production `datrixops` project, its volumes
and its ports were not modified. Both test projects, volumes, generated
credentials and images were removed after verification.

Environment:

- Ubuntu 25.04 host
- Docker Engine 29.2.1
- Docker Compose 5.0.2
- PostgreSQL 16 in a new named volume
- Dedicated HTTP ports `39080` and `39081`
- High-risk Agent features disabled

This is not the clean Ubuntu 24.04 release gate.

## Defects found and fixed during the run

1. Migration discovery accepted macOS AppleDouble files such as
   `._20260712_001_create_auth_tables.sql`. Migration selection now ignores
   hidden files and has a regression test.
2. Clean restore could call `pg_restore` before a new PostgreSQL instance was
   ready. Restore now polls `pg_isready` for up to 60 seconds and fails with an
   explicit error if readiness is not reached.

## Remaining release gates

- Repeat installation and restore on a genuinely clean Ubuntu 24.04 host.
- Deliver and recover through at least one real external notification provider.
- Exercise upgrade rollback and Agent update rollback.
- Complete administrator-managed users and roles, then run Viewer mutation E2E.
- Obtain successful hosted CI and signed tagged-release workflow runs.

Until these gates pass, the repository must not be described as
production-ready.
