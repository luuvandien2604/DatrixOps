## Create the local administrator

After installing the Control Plane, open the `/login` URL printed by the
installer. The default username is `admin`; the generated password is shown
once and is not stored in plaintext. `/opt/datrixops/.admin-credentials`
contains only the username. Public signup is disabled by default. If the
password is lost, run `datrix reset-password`.

## Add a server

1. Open **Servers → Add Server**.
2. Enter a server name and select its platform.
3. Create the server record.
4. Copy the exact Agent command generated by the Dashboard.
5. Run it on the target server with the requested privileges.

The command contains a short-lived enrollment token for that server. Do not
place it in public chat, support tickets or Git.

The server may show **Offline** before its first heartbeat. If it does not
become **Online**, see [Agent installation](/docs/en/getting-started/installation)
and [Troubleshooting](/docs/en/troubleshooting/common-issues).
